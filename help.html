MidiJoy Configurator

Веб-интерфейс для настройки MIDI-контроллера на базе геймпада Logitech F310

Быстрый старт

  1. Подключите MidiJoy к компьютеру через USB
  2. Откройте конфигуратор в браузере Chrome/Edge
  3. Нажмите Find MIDI Device
  4. Выберите устройство в появившемся окне (обычно "USB Serial Device")
  5. После подключения отобразится версия прошивки

Основные кнопки

Кнопка Описание
Find MIDI Device Подключиться к устройству / Отключиться
Read Config Прочитать текущую конфигурацию из устройства
Save to Flash Сохранить конфигурацию в EEPROM (сохранится после перезагрузки)
Reset Defaults Сбросить настройки на заводские

Панель настроек (Settings)

Нажмите кнопку Settings справа для открытия панели конфигурации.

MIDI Channel

Выберите MIDI-канал (1-16). По умолчанию используется канал 10 для совместимости с Roland SP-404 MK2.

Face Buttons (A, B, X, Y)

Настройка кнопок A, B, X, Y. Каждая кнопка отправляет MIDI CC сообщение при нажатии.

Shoulder Buttons (LB, RB, LT, RT)

Плечевые кнопки и триггеры. Работают аналогично Face Buttons.

Center Buttons (Back, Start)

Центральные кнопки геймпада.

Stick Buttons (L3, R3)

Нажатие на аналоговые стики.

D-Pad

Крестовина (вверх, вниз, влево, вправо).

Analog Sticks (CC Mode)

Аналоговые стики отправляют непрерывные MIDI CC значения:

  • Центр: значение ~64
  • Крайнее положение: 0 или 127

Идеально подходят для управления эффектами в реальном времени.

Порядок работы

  1. Подключитесь к устройству
  2. Нажмите Read Config чтобы загрузить текущие настройки
  3. Откройте панель Settings
  4. Измените нужные параметры
  5. Нажмите Apply Configuration в панели настроек
  6. Проверьте работу на SVG-изображении джойстика
  7. Нажмите Save to Flash для сохранения в память устройства
Совет: Если вы не нажмёте "Save to Flash", настройки сбросятся после перезагрузки устройства.
Важно: Конфигуратор работает только в браузерах Chrome и Edge (требуется Web Serial API).

Визуализация

На главной странице отображается SVG-изображение геймпада. При нажатии кнопок на реальном джойстике, соответствующие элементы подсвечиваются на экране.

  • Кнопки меняют цвет при нажатии
  • Стики показывают текущую позицию белой точкой
  • D-Pad подсвечивает активные направления

Решение проблем

Устройство не найдено

  • Убедитесь что MidiJoy подключён к USB
  • Попробуйте другой USB-порт
  • Используйте Chrome или Edge

Настройки не сохраняются

  • Нажмите "Save to Flash" после применения настроек
  • Дождитесь сообщения "Configuration saved!"

Неправильные значения после перезагрузки

  • Прошейте актуальную версию прошивки
  • Нажмите "Reset Defaults" и заново настройте
